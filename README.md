# Sprout for Mac

Downloads for Sprout, a budget app for Mac: https://sprout-demo.onrender.com

Apple chip Macs: Sprout-Apple-Chip.dmg. Intel Macs: Sprout-Intel.dmg.

The first time you open Sprout, macOS can't check it, because it isn't from the App Store. Open System Settings, then Privacy & Security, scroll down and press Open Anyway. You only do this once.
